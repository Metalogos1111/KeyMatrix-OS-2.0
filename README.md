- **Tier 5 [PROVEN]** — Verified by independent multi-source cryptographic proofs & canonical texts.
- **Tier 4 [REPRODUCED]** — Replicated across multiple deterministic execution runs.
- **Tier 3 [VERIFIED]** — Verified by TEE sandbox or formal math gate.
- **Tier 2 [OBSERVED]** — Empirically recorded telemetry or peer witness.
