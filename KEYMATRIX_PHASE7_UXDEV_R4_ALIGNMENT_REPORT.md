## 1. 📂 Контрольный перечень материализованных контрактов (Phase 7.0/7.1)

В корневой директории развернуты и верифицированы следующие неизменяемые артефакты:

1. **`KEYMATRIX_SOURCE_CONTINUITY_LEDGER.json` (Source)**
   * Содержит эталонные SHA-256 хэши и DID суверенных авторов для ключевых рантайм-файлов. Препятствует несанкционированному изменению ядра происхождения.
2. **`KEYMATRIX_EXECUTION_TRACE_PACK_001.json` (Evidence)**
   * Фиксирует воспроизводимые двухэтапные следы выполнения (`second_run_hash`), доказывающие детерминированность локальных тестов и функций верификации.
3. **`KEYMATRIX_IDENTITY_PASSPORTS_001.json` (Core Passports)**
   * Хранит официальные паспорта 7 вычислительных поверхностей с жесткой фиксацией лимитов доказуемости (`OBSERVED`).
4. **`KEYMATRIX_BENCHMARK_BASELINE_001.json` (Benchmarks)**
   * Закрепляет базовые показатели производительности, TTI, размеры буферизации логов и ограничения сетевых консенсусов.
5. **`KEYMATRIX_ADR_DRAFT_REGISTRY.json` (ADR)**
   * Фиксирует открытые вопросы архитектуры (ADR-001, ADR-004, ADR-006, ADR-012, ADR-013) без преждевременного автоматического закрытия.
6. **`KEYMATRIX_ANTIGRAVITY_INPUT_PACKAGE_001.json` (Transition Contract)**
   * Формирует полный структурированный пакет входных улик и деклараций для безопасной передачи в Antigravity.
